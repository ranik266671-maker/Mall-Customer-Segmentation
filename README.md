Mall Customer Segmentation

Project Overview

This is a Machine Learning project that uses K-Means Clustering to group mall customers based on their Annual Income and Spending Score.

Dataset

- Mall_Customers.csv

Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- K-Means Clustering

Project Files

- "train_model.py" — Python code for training the model.
- "Mall_Customers.csv" — Customer dataset.
- "customer_segments.csv" — Customer segmentation results.
- "customer_segments.png" — Customer segmentation visualization.
- "customer_segmentation_model.pkl" — Saved trained model.

Model Evaluation

Silhouette Score: 0.555

How to Run

1. Install Python.
2. Install the required libraries.
3. Run "python train_model.py".
